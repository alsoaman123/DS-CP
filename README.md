# DS-CP
Game Quest Engine/Manager

How to run this code - 

1. Open new terminal
2. Enter this command -> gcc -std=c11 -Wall -Wextra -pedantic main.c backend.c -o GameQuestManager.exe
3. Write this command next -> ./GameQuestManager

NOTE - This currently makes items and quests on the assumption that everything we do is pre decided and at the end the logic of the quests working in sequence aligns itself as per the fields we enter. Meaning we have the Idea in mind of which quest unlocks what or requires what and we add quests and inventory items without any errors.
